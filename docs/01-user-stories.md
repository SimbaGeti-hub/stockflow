# User stories

Format: As a [role], I want [action], so that [benefit].

## Vertical slice

- As a business owner, I want to register and create a workspace, so that I can start managing my business.
- As an owner, I want to create a product, so that I can sell and track it.
- As an owner, I want to record stock received, so that my stock count is correct.
- As a cashier, I want to record a sale, so that the customer gets a receipt and stock goes down.
